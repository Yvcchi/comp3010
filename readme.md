# BLEVE Peak Pressure Prediction

**COMP3010 Machine Learning Project — Curtin University**

This project uses the data in `train.csv` and `test.csv` to predict the peak pressure generated by a Boiling Liquid Expanding Vapour Explosion (BLEVE). The workflow, from data preparation through model training and prediction export, is in [`main.ipynb`](./main.ipynb).

## Project files

| File | Description |
| --- | --- |
| `main.ipynb` | Data cleaning, feature engineering, model training, evaluation, and prediction export |
| `train.csv` | Training data: 10,050 rows and 25 columns, including the target |
| `test.csv` | Test data: 3,203 rows and 24 columns |
| `prediction_ensemble (4).csv` | Supplied ensemble prediction file |

The target is `Target Pressure (bar)`. `ID` is removed from the model features and retained to identify rows in exported predictions. Other input fields describe tank and liquid properties, BLEVE and vapour heights, obstacles, and sensor positions.

## Workflow

1. Load the training and test CSV files and remove `ID` from the feature data.
2. Remove training rows without a target (10 rows in the notebook run). Impute numeric missing values with the training-set median and categorical missing values with the training-set most frequent value.
3. Remove duplicate training rows (50 in the notebook run).
4. Clip numeric features to the training-set IQR bounds (1.5 × IQR); use the same bounds for the test data. Set negative `BLEVE Height (m)` values to zero.
5. Create five features: tank width-to-length ratio, vapour-height-to-tank-height ratio, obstacle area, relative obstacle distance, and vapour-minus-liquid temperature difference.
6. Standardize the `Status` labels and one-hot encode `Status` and `Sensor Position Side`. Align the test feature columns with the training columns.
7. Select features whose absolute correlation with the target is greater than 0.05. The notebook run retained 22 features, then applied `StandardScaler`.
8. Evaluate/tune models with shuffled 5-fold cross-validation (`random_state=42`) using MAPE as the search score.

## Models and results

| Model | Notebook implementation | Reported result |
| --- | --- | --- |
| Linear model | Vectorized gradient descent (2,000 iterations; learning rate 0.01) | 687 negative predictions on the test set |
| Random Forest | `RandomForestRegressor`; 20 randomized-search configurations | 5-fold CV MAPE: **0.1901 ± 0.0059** |
| MLP | `MLPRegressor` with early stopping; 30 randomized-search configurations | Best-search CV MAPE: **0.2173** |
| Ensemble | Arithmetic mean of Random Forest and MLP predictions | Exported; no separate cross-validation score is reported |

The best Random Forest parameters were `n_estimators=300`, `max_depth=20`, `min_samples_split=2`, `min_samples_leaf=1`, and `max_features=0.5`. The best MLP parameters were `hidden_layer_sizes=(100, 100)`, `activation='relu'`, `alpha=0.01`, `learning_rate_init=0.0005`, and `batch_size=32`.

The Random Forest had the lowest reported cross-validation MAPE among the tuned models and produced no negative test predictions in the notebook run. The ensemble file contains the row-wise average of Random Forest and MLP predictions; the notebook does not report an ensemble validation metric.

## Run the notebook

Use Python 3.8 or later with:

- pandas
- NumPy
- matplotlib
- scikit-learn
- Jupyter Notebook or Google Colab

Install the Python packages with:

```bash
pip install pandas numpy matplotlib scikit-learn
```

Keep `train.csv` and `test.csv` in the notebook's working directory, then run the cells in `main.ipynb` from top to bottom. In Google Colab, upload both CSV files before running the notebook.

The notebook writes these files when the corresponding cells are run:

- `prediction.csv` — linear model
- `predictionforest.csv` — Random Forest
- `predictionmlp.csv` — MLP
- `prediction_ensemble.csv` — Random Forest/MLP average

Each prediction CSV contains `ID` and `Target Pressure (bar)`. The final notebook cell uses the Google Colab download API; when running outside Colab, skip that cell and retrieve the generated CSV from the working directory.

## Notes

- Cross-validation is run after imputation, IQR clipping, feature selection, and scaling have been fit using the full training data. Therefore the reported CV scores may be optimistic; a leakage-safe evaluation would fit these preprocessing steps separately within each fold.
- The checked-in prediction file is named `prediction_ensemble (4).csv`; rerunning the notebook writes `prediction_ensemble.csv`.
